# Sec-blind Review — Full Project Audit

Delegated to Opus 5.5 High with superpowers + secskills-core (crypto, vuln, review).
Date: 2026-11-17.

## 1. Direction Assessment

The architecture matches the commercial DRM pattern the briefing promises: client with lazy symbol binding + sentinel + HWID bind + AES-GCM entitled module + HMAC session binding + Go server with Redis/PG. Phases 1–6 are coherent, HKDF-Expand key separation is resolved on both sides, and the end-to-end flow works. Fundamental decisions are on the right track and need not be revisited before new features.

What blocks immediate ship is **execution**, not design: shutdown race between `heartbeat` and `net`, incomplete rate-limit enforcement, activation-code brute force against `/auth/login` without consuming the nonce, TLS terminated by nginx without the server knowing the peer, and about a dozen minor operational TODOs. None are re-architecture; they are edge cuts to close before the commercial deploy.

## 2. Findings

### CRITICAL

**[CRITICAL] Shutdown race: net::shutdown closes handles used by the heartbeat thread**
File: `Project1/src/heartbeat.cpp:144-162` + `Project1/src/Main.cpp:203-205,219`
Problem: heartbeat::stop() waits only 10 s. If the thread is blocked inside WinHttpSendRequest/WinHttpReceiveResponse (TLS handshake + round-trip can easily exceed that), stop() returns with the thread alive; Main.cpp then calls net::shutdown() which closes s_conn/s_session, and the thread wakes up touching freed handles.
Impact: UAF / crash in production during a normal shutdown with slow network or a hanging server.
Fix: before net::shutdown(), skip the join on timeout and swap it for net::cancel_in_flight() which calls WinHttpCloseHandle(hRequest) on the current handle (kept in s_cs). Or raise the timeout and have the thread signal completed_event before net::shutdown proceeds.

**[CRITICAL] /auth/login: activation-code brute force without spending the nonce**
File: `server/internal/api/api.go:205-233`
Problem: the check order is (1) LicenseByKey → (2) banned/kill → (3) TakeChallenge (GETDEL) → (4) HMAC. If the activation code is unknown, it returns 401 BEFORE consuming the nonce. An attacker with 1 valid nonce for their HWID can try N activation codes within the 60 s TTL.
Impact: with a 30-rpm per-IP rate-limit, that's ~1800 attempts/hour per IP; via IPv6/botnet makes enforcement unviable.
Fix: TakeChallenge first (GETDEL is one-shot) and only then LicenseByKey; if the nonce doesn't match, 401 without leaking anything.

**[CRITICAL] Rate-limit not enforced on /heartbeat, /payload/fetch, /rpc/call**
File: `server/internal/api/api.go:343-614`
Problem: per_ip_rpm/per_hwid_rpm fields are read but only /auth/challenge and /auth/login call s.rateLimit. Any client with a valid token can hammer /payload/fetch (AES-GCM + HKDF-Expand + Redis + PG on every call).
Impact: trivial DoS with a legitimate license.
Fix: s.rateLimit(ctx, clientIP(r), sess.HWID) after resolving sess in the three handlers; lower limit on /payload/fetch (e.g. 6 rpm).

### HIGH

**[HIGH] Dual TLS fingerprint points to the same self-signed integration hash**
File: `Project1/src/net.cpp:161-162`
Fix (pre-deploy): replace both with real hashes (current + backup) and add an assert in the release build.

**[HIGH] Plain-HTTP TLS without a way to detect nginx bypass**
File: `server/cmd/server/main.go:94-103`
Fix: listen 127.0.0.1 only + firewall, OR native TLS in http.Server, OR reject if X-Forwarded-Proto != "https".

**[HIGH] HWID bind TOCTOU: cooldown read and upsert are not atomic**
File: `server/internal/api/api.go:260-286`
Fix: transaction with SELECT ... FOR UPDATE, or conditional upsert (UPDATE ... WHERE last_change < now() - interval '30 days').

**[HIGH] /rpc/call without replay-protection token**
File: `server/internal/api/api.go:537-614`
Fix: add a nonce in the request, store `rpc_nonce:<token>:<nonce>` in Redis with TTL = 2*skew.

**[HIGH] Heartbeat refreshes TTL even with kill=true**
File: `server/internal/api/api.go:407-417`
Fix: if killed, DeleteSession and do not call RefreshSession/RememberLatestToken.

**[HIGH] fgets can truncate activation codes >127 chars without feedback**
File: `Project1/src/Main.cpp:70-77`
Fix: 256 B buffer or std::getline.

**[HIGH] No graceful shutdown in the server**
File: `server/cmd/server/main.go:103`
Fix: signal.Notify + hs.Shutdown with a 30 s context.

**[HIGH] s_running / s_reason accessed cross-thread without atomic/barrier**
File: `Project1/src/heartbeat.cpp:32,43-100,164` + `Project1/src/sentinel.cpp:27-83`
Fix: std::atomic<bool> with acquire/release.

**[HIGH] Zero observability in the server**
File: `server/*`
Fix: structured log/slog middleware; counters in abuse_log for HMAC-fail on /heartbeat and /rpc/call.

### MEDIUM

- **Timing side-channel: license existence leaks** (`api.go:205-222`) — collapse error messages.
- **Server session-binding TTL 24 h without kill invalidation** (`api.go:517`) — document or reduce to 1 h.
- **Clock rollback bypasses session-binding expiry** (`watermark.cpp:144-151`) — documented limitation.
- **HWID cooldown blocks first rebind for 30 d** (`postgres.go:84-89` + `api.go:277`) — only set last_change when curBind != req.HWID.
- **PRK (session_key) travels and persists in Redis as base64** (`api.go:322`, `redis.go:38-52`) — document as secret-tier storage, ACL + TLS + rotation.
- **HKDFExpand drops the error from io.ReadFull** (`hkdf.go:28-33`) — return error.
- **http.MaxBytesReader with nil ResponseWriter** (`api.go:95`) — pass w for a correct 413.
- **Server doesn't handle Postgres DNS/connect at startup** (`main.go:66-70`) — pool.Ping(ctx) + fatal.
- **Canonical `|` delimiter assumes a method without a pipe** (`rpc.cpp:76-82`) — whitelist on the server.

### LOW

- **Session-binding hwid field: doc says SHA-256(hex_string), code uses hex-decode** (`SERVER_SPEC.md:174` vs `watermark.cpp:129-133`) — edit the doc.
- **LogAbuse detached context may leak during shutdown** (`postgres.go:118-126`) — accept.
- **isValidHWID accepts case-sensitive strings without a specific error** (`api.go:125-136`) — no action.
- **rpc.cpp parameter named session_key but expects k_rpc** (`rpc.h` + `rpc.cpp:53-57, 85-87`) — rename to rpc_key.
